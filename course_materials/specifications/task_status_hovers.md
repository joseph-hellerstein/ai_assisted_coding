# Task Status Hovers

This feature provides a short status for each of the tasks of the Survey Manager. Each is provided by a hover over the task text box on the landing page.

* For Survey Maker, list the available surveys, and the number of questions.
* For Survey Taker, list the progress on survey questions for each survey
    * <survey name> <n/m>
    * where n is the number of questions completed and m is the total number of questions
* For Survey Analyzer, list the number of responses for each survey.
