# Learners

Attendees will be academics who want to improve their productivity with building applications in Python. Attendees should
have substantive experience with Python programming and ``github`` with some exposure to AI chatbots. Their skills include:

* They have written python applications in excess of 1,000 lines of code.
* They have a github repository with the following:
  * at least two Python modules;
  * one module is a dependency of the other; and
  * there are unit tests for both modules
* They have at least one ``github`` repository in which they are the primary contributor. They know how to: (a) create a new repository; (b) clone an existing repository; (c) add files to the client repo; (d) create a commit; (e) push a commit.
* They have developed an application in ``VSCode``.
* They have used a large language model to write code.
* They have written basic HTML tags.
* Ideally, they have created a PyPI package.

Attendees are expected to complete the following prior to the start of the course:

1. Learners have a laptop.
2. Learners have completed course on LLM basics: setup on VSCode; effective prompting; tokens, context
3. Student has VSCode installed on their computer.
4. Create a ``github`` repository with the title ``ai_assisted_python_programming``.
5. Install Dash on your laptop.
6. Write a Dash application that creates a web page that says "Hello World!". All the files for the application should be in your github repository.
